════════════════════════════════════

TERMINAL 1 - Docker:
  cd C:\Projetos\Poker
  docker-compose up -d

TERMINAL 2 - Backend:
  cd C:\Projetos\Poker\packages\backend
  npm install
  npx prisma migrate dev
  npm run dev

TERMINAL 3 - Frontend:
  cd C:\Projetos\Poker\packages\web
  npm install
  npm run dev

Depois abra: http://localhost:3002

════════════════════════════════════
🔧 TROUBLESHOOTING
════════════════════════════════════

Se falhar em setup.ps1:
  Abra PowerShell como ADMINISTRADOR e tente novamente

Se porta já está em uso:
  netstat -ano | findstr :3002
  taskkill /PID [número] /F

Se banco não conecta:
  docker ps
  docker-compose down
  docker-compose up -d
